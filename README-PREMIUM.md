# Ayushi & Ishant — Premium animated invitation

This version is events-only and has a visible animated SVG bride and groom in the hero, an illuminated arch, drifting golden petals, animated event decorations, responsive mobile layout, and reduced-motion accessibility support. No photographs, external animation libraries, or build tools are needed.

## Publish
Upload **index.html, styles.css, premium.css, script.js, and assets/** to the ROOT of your existing GitHub Pages repository. Ensure `premium.css` is uploaded; without it the animation is much less visible. GitHub Pages may take a few minutes to update. Hard-refresh or test in a private browser tab to bypass cached CSS.

## Important
Replace `RSVP_BASE_URL` in `script.js` with your real form URL. The default `https://forms.google.com/` is a placeholder. Your `?guest=...&id=...` personalized links remain supported. Check the event details and venue before sharing.
