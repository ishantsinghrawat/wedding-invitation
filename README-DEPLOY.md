# Ayushi & Ishant — animated wedding invitation

This repository is ready for GitHub Pages. It includes all website files, the uploaded wedding illustration converted into a looping GIF, and a static fallback image.

## Deploy
Upload the **contents** of this folder to the root of `ishantsinghrawat/wedding-invitation` (not the parent folder). Commit changes; wait for GitHub Pages. Hard-refresh if you see an older version.

## Customize
- Wedding details: `index.html`
- Date, personalized guest query parameters and RSVP URL: `script.js`
- Visual styling: `styles.css` and `premium.css`
- Animated artwork: `assets/images/wedding-scene.gif`

The GIF is animated using a subtle zoom, floating petals, and fire flicker over the **exact image you provided**. The figures in the source artwork are not separately rigged, so their arms and clothing do not move independently.

**Before sending:** Replace `RSVP_BASE_URL` in `script.js` with your real RSVP form.
